참고. 1) 두 엔드 서비스는 같은 backend 컨테이너를 공유 — account · organization · billing · community · product-b · llmgateway · agent 는 AWS / K3s 양쪽에서 동일 이미지로 동작(HA·오프라인 양립).
2) AWS 전용 = 매니지드 데이터 플레인(Aurora·EventBridge·Batch·SES·BI) + datasets. K3s 전용 = rag(문서 검색), 클러스터 내장 DB·저장소·버스. (사내 LLM 추론·CI/CD·관측은 별도 운영 플랫폼 장표 참조)
3) Product A / Product B = "제품 서비스" — 단순 BFF가 아니라 제품 도메인 로직 + 하위 서비스 합성을 함께 수행.
4) Product B 핵심 가치 = 입력·문서의 개인정보를 비식별 처리한 뒤 LLM에 전달해 데이터 유출 없이 LLM을 활용.
5) auth-web 는 두 제품 공통 인증 관문(양 컬럼에 표기).
