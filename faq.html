개발 경력이 어떻게 되나요?​

현재 10년차 개발자입니다. 2016년 IoT 솔루션 개발로 시작해 3D 그래픽스를 6년 넘게 다뤘고, 이후 백엔드와 인프라로 옮겨 지금은 마이크로서비스와 온프레미스 AI 환경을 주로 만듭니다. 자세한 이력은 Projects 에 정리해 두었습니다.

좋아하는 기술 스택​

  • Database: PostgreSQL
  • BackEnd: Python, FastAPI
  • FrontEnd: TypeScript, NextJS
  • 3D Graphics: Three.js(WebGL), Unity(Game Engine)

잘하는 것​

  • 환경설정에 진심인 편 (Formatter, Linter 씁시다)
  • SaaS 플랫폼 SDK 개발 (Multi-tanent / 구조화)
  • 3D 그래픽스 보편화 / 최적화
  • 성능 최적화 (Memory 친화적 / File-io ~ MemCache 이해)

못하는 것​

  • 용어 구사 능력 (인라인함수 = IIFE = 즉시실행함수 = 애로우펑션 = 어이구야...)
