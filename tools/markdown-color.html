마크다운 글자색·형광펜 생성기

마크다운 문법에는 색상이 없어서 HTML span 으로 색을 냅니다. 문장과 색을 고르면 코드를 만들어 줍니다. GitHub 은 HTML 의 style 을 지우기 때문에 GitHub 용 코드는 따로 드립니다.

강조할 문장
HTML (Typora, Obsidian, Docusaurus, 티스토리 등)
<span style="color:#e03131">강조할 문장</span>
GitHub (README, 이슈, PR)
$\color{#e03131}{\textsf{강조할 문장}}$

어디서 어떤 코드를 쓰나요

  • HTML 코드는 마크다운 안에 HTML 을 허용하는 편집기에서 그대로 보입니다.
  • GitHub 은 보안상 style 속성을 지워서 HTML 코드의 색이 사라집니다. 대신 수식 문법으로 색과 크기를 냅니다. 형광펜은 GitHub 에서 지원하지 않습니다.
  • Notion 은 HTML 을 받지 않습니다. 글자를 선택한 뒤 메뉴의 색상 기능을 쓰세요.

문법을 하나씩 설명한 글은 Markdown 글자 크기, 색상, 형광펜 설정 방법에 있습니다. 다른 도구는 개발 도구 모음에서 볼 수 있습니다.
